# Verba

Застосунок для вивчення англійської (від B1) та іспанської (з нуля).
Латинське *verbum* — «слово», і водночас верба: назва про те, як ростуть знання.
Працює як звичайний сайт і як застосунок на телефоні — офлайн, на весь екран, з іконкою на головному екрані.

## Що всередині

| файл | що це |
|---|---|
| `index.html` | увесь застосунок: уроки, вправи, картки, тексти, журнал помилок |
| `manifest.webmanifest` | опис застосунку: назва, іконки, колір, ярлики |
| `sw.js` | сервіс-воркер — офлайн-режим і кеш |
| `icon-192.png`, `icon-512.png` | іконки застосунку |
| `icon-maskable-*.png` | іконки для Android (з безпечною зоною) |
| `apple-touch-icon.png` | іконка для iPhone |
| `favicon-32.png` | іконка вкладки браузера |

Усі шляхи відносні, тому теку можна покласти в будь-який підкаталог.

## Публікація на GitHub Pages

1. Створіть новий репозиторій `verba` (публічний).
2. Завантажте туди **вміст** цієї теки — усі файли мають лежати в корені репозиторію, поруч, без вкладеної папки.
3. Settings → Pages → Source: `Deploy from a branch`, гілка `main`, тека `/ (root)` → Save.
4. За хвилину-дві сайт буде на `https://<ваш-нік>.github.io/verba/`.

Через термінал (Ubuntu):

```bash
cd ~/verba
git init
git add .
git commit -m "Verba"
git branch -M main
git remote add origin git@github.com:<ваш-нік>/verba.git
git push -u origin main
```

## Встановлення на телефон

**Android (Chrome).** Відкрийте посилання → на головному екрані застосунку кнопка «Встановити», або меню ⋮ → «Встановити застосунок».

**iPhone (Safari).** Відкрийте посилання → «Поділитися» → «На екран «Домівка».

Після встановлення застосунок відкривається без адресного рядка й працює без інтернету.
Озвучення (аудіювання, читання слів і текстів) використовує голоси системи — на Android та iOS вони вбудовані.

## Оновлення

Замініть `index.html` у репозиторії й **змініть версію кеша** в `sw.js`:

```js
const V = "verba-v2";   // було v1
```

Без цього телефон показуватиме стару збережену версію.

## Дані

Прогрес, картки, домашні завдання і журнал помилок зберігаються локально в браузері (`localStorage`, ключ `verba.v1`).
Якщо ви вже користувалися попередньою версією під назвою «Мовник», прогрес перенесеться автоматично при першому відкритті.
Перенести на інший пристрій: головний екран → «Резервна копія» → «Зберегти файл», потім на іншому пристрої → «Відновити».
